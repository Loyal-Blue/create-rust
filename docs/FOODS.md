# Item behavior: content 0.8.1 / native 0.8.0

These are authored port values, not verified replicas of the Java mod’s values.

| Item | Behavior |
| --- | --- |
| Bar of chocolate | 6 food points, 7.2 saturation |
| Honeyed apple | 8 food points, 9.6 saturation |
| Chocolate glazed berries | 6 food points, 7.2 saturation |
| Builder’s tea | Two-second drink, usable at full hunger; Haste I for 3 minutes; returns a glass bottle |
| Nugget of experience | Native local-host right-click consumes one nugget and grants 3 XP |

Food, drinking, effects and bottle returns use ordinary Horizon item components, including in content-only installs. Ordinary engine item-use and inventory rules apply. XP nuggets require native support; remote XP-use controls remain unimplemented. Creative mode follows the host’s ordinary consume-held rule. No running-game consumption or multiplayer verification has been performed.
